## 2. Search Engine Optimization (SEO) Architecture
To ensure absolute search dominance and high organic visibility for **tiwantiwa.com**:
- **Semantic HTML & Metadata**: Every page leverages strict hierarchical heading tags (`H1`, `H2`, `H3`), unique page titles, optimized meta descriptions (< 160 characters), and clean canonical URLs.
- **Structured JSON-LD Schema**: Automated Article and WebSite schema markup injected into every dispatch header to enable rich Google search snippets and knowledge graph indexing.
- **XML Sitemaps & RSS Syndication**: Automated generation of `/public/sitemap-index.xml` and `/public/rss.xml` on every build to guarantee rapid crawler indexing.
- **Core Web Vitals & Speed**: Pure static HTML output via Astro eliminates server latency (sub-15ms TTFB), ensuring top rankings on mobile-first indexing.
